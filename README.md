# Video User Study

Anonymous video ranking study website.

Website: https://generalwhite.github.io/FastInteract_User_Study/

## Deployment

In repository Settings → Pages, choose Deploy from a branch, main, / (root).

## Study status

The website is connected to the study backend. Individual invitation links save rankings to the server. Visits without an invitation run in demo mode and save answers only in the current browser. Invitation lists remain private and are distributed separately by the organizer.

Only public website assets belong in this repository. Never upload organizer files, invitation tables, private method mappings, database seed files, or administrator credentials.

## Task versions

The frontend supports existing eight-candidate tasks and upgraded nine-candidate tasks. Each invitation retains its original URL. Candidate counts come from the server-assigned task; nine-candidate tasks use a three-by-three comparison grid. Responses carry a cohort identifier, and organizers must report the two cohorts separately.
